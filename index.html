DTVN — Distributed Ticket Validation Network

VERIFIED REV —

Byzantine fault-tolerant P2P ticket validation system built in Go

Event ticketing has a double-spend problem — how do you prevent the same ticket from being validated at two different gates simultaneously when you can't rely on a central server? DTVN solves this with a Byzantine fault-tolerant peer-to-peer network. Each validator node runs PBFT consensus to agree on ticket state changes, gossip protocols to disseminate messages, and vector clocks to resolve conflicts from concurrent updates. The system tolerates up to a third of its nodes being actively malicious and still reaches correct consensus. Built entirely in Go with libp2p for networking, Protobuf for wire format, and BoltDB for persistence — plus a D3.js dashboard that lets you visualize the live P2P mesh topology.

  • PBFT 3-phase consensus with view change recovery
  • Gossip protocol with Bloom filter deduplication and anti-entropy sync
  • libp2p networking with Kademlia DHT peer discovery
  • Vector clocks for causality tracking and conflict resolution
  • Web dashboard with D3.js network topology visualization
  • Byzantine fault tolerance simulator with network partition testing
  • ~12,800 lines of Go with ~8,300 lines of tests

TCP SYN Flood Detector

VERIFIED REV —

High-performance userspace daemon for real-time DDoS detection and mitigation

A C11 daemon that detects and mitigates TCP SYN flood attacks through real-time packet inspection via netfilter/NFQUEUE, sliding window rate limiting, and automatic ipset-based firewall rule management. Handles 65,000+ SYN packets/second at ~45ms detection latency. Built with a V-Model SDLC approach, including 13 test suites with AFL++ fuzzing and CodeQL security scanning.

  • 65,000+ PPS throughput with ~45ms detection latency
  • Dual capture: NFQUEUE (primary) and raw socket + BPF (fallback)
  • Sliding window rate limiting with /proc/net/tcp SYN_RECV validation
  • 13 test suites including AFL++ fuzzing
  • Security-hardened: CAP_NET_ADMIN + CAP_NET_RAW only, no full root
  • CodeQL security scanning and CI/CD pipeline
